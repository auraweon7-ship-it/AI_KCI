단계별 제작 파이프라인

주제 선정에서 YouTube 업로드까지, 5단계 자동화 워크플로우가 순차적으로 실행됩니다

1
기획 (Pre-Production)

주제 선정 → 대본 기획 → 대본 작성
Claude AI가 주제 분석, 구조 설계, 나레이션 대본까지 자동 생성

Claude API (claude-sonnet-4-20250514)
2
시각 소재 (Visual Assets)

대본의 장면 지시에 따라 ChatGPT Images 2.0이 고해상도 일러스트를 배치 생성
프롬프트 자동 생성 → 개별 검토/수정 → 일괄 또는 개별 이미지 생성

GPT Image API (high, 1536×1024)
3
음성 제작 (Audio Production)

대본 텍스트를 ElevenLabs TTS로 자연스러운 나레이션 음성 변환
음성 선택, 안정성/유사도 파라미터 조절 가능

ElevenLabs API (eleven_multilingual_v2)
4
영상 합성 (Video Rendering)

이미지 + 음성 → Ken Burns 줌팬 효과 적용 MP4 영상으로 합성
오디오 길이 기반 자동 타이밍, 1080p 렌더링

FFmpeg (zoompan, concat)
5
퍼블리싱 (Publishing)

SEO 최적화 메타데이터 생성 → 썸네일 디자인 → YouTube 직접 업로드
인트로 생성까지 원스톱 완료

YouTube Data API v3 + OAuth 2.0
