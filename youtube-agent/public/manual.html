🔑 API 키 발급 가이드

.env 파일에 아래 API 키를 입력합니다. 모든 키가 없어도 해당 기능만 비활성화되고 나머지는 정상 작동합니다.

1. Anthropic (Claude AI) 필수
  • console.anthropic.com 접속 → 회원가입
  • API Keys → Create Key → 복사
  • ANTHROPIC_API_KEY=sk-ant-xxxxx

용도: 주제 추천, 대본 기획/작성, 메타데이터, 인트로, 썸네일 문구, 이중 자막 번역

2. OpenAI (GPT Image) 이미지 생성 시 필수
  • platform.openai.com 접속
  • API Keys → Create new secret key → 복사
  • OPENAI_API_KEY=sk-xxxxx

용도: 장면별 이미지 생성 (gpt-image-1), 썸네일 이미지 생성

3. ElevenLabs (TTS) 음성 생성 시 필수
  • elevenlabs.io 접속 → 회원가입
  • Profile → API Key → 복사
  • ELEVENLABS_API_KEY=xxxxx

용도: 대본 → 나레이션 음성 변환 (다국어 지원)

4. Pexels (스톡 영상) 영상 모드 시 필요
  • pexels.com/api 접속 → 무료 API 키 발급
  • PEXELS_API_KEY=xxxxx

용도: 장면별 스톡 영상 클립 다운로드 (이미지 대신 실사 영상 사용 시)

5. YouTube Data API (업로드) 선택
  • Google Cloud Console → 프로젝트 생성
  • YouTube Data API v3 활성화
  • OAuth 2.0 Client ID 생성 (웹 애플리케이션)
  • Redirect URI: http://localhost:3003/api/youtube/callback
YOUTUBE_CLIENT_ID=xxxxx.apps.googleusercontent.com
YOUTUBE_CLIENT_SECRET=xxxxx
YOUTUBE_REDIRECT_URI=http://localhost:3003/api/youtube/callback

완성된 .env 예시

ANTHROPIC_API_KEY=sk-ant-api03-xxxxx
OPENAI_API_KEY=sk-xxxxx
ELEVENLABS_API_KEY=xxxxx
PEXELS_API_KEY=xxxxx
YOUTUBE_CLIENT_ID=xxxxx.apps.googleusercontent.com
YOUTUBE_CLIENT_SECRET=xxxxx
YOUTUBE_REDIRECT_URI=http://localhost:3003/api/youtube/callback

📄 대본 텍스트 (참고 자료)

영상 언어 선택 아래에 위치한 빨간색 체크박스 옵션입니다. 기존 논문, 기사, 보고서, 메모 등 참고할 원본 텍스트가 있을 때 사용합니다.

사용 방법

  1. 📄 대본 텍스트 (참고 자료) 체크박스를 클릭하여 활성화
  2. 펼쳐진 텍스트 영역에 참고할 원본 텍스트를 붙여넣기
  3. 🚀 자동 제작 시작 클릭 — 기획·대본 생성 시 이 텍스트를 핵심 자료로 참고

동작 방식

상태기획 (2단계)대본 (3단계)
체크 해제 (기본)AI가 주제만으로 자율 기획AI가 기획안 기반 자율 작성
체크 + 텍스트 입력입력 텍스트의 내용·구조·핵심 정보를 반영하여 기획입력 텍스트의 사실 관계·핵심 정보를 정확히 반영하되 나레이션으로 재구성
참고 텍스트는 기획에 최대 6,000자, 대본 생성에 최대 8,000자까지 반영됩니다. 긴 텍스트는 핵심 부분만 붙여넣는 것이 효과적입니다.
4단계 이후(이미지, TTS, 영상 합성 등)에는 영향을 주지 않습니다. 오직 기획과 대본 작성 단계에서만 참고됩니다.

🚀 자동 제작 시작 버튼을 누르면 10단계가 순차 실행되며, 각 단계의 진행 상황과 결과가 실시간으로 표시됩니다.

1 주제 선정

사이드바 주제 선정 메뉴에서 영상 주제를 결정합니다.

방법 1: 직접 입력

  1. 상단 입력란에 주제를 직접 입력 (예: "베트남 전쟁 속 병사들의 고독과 연대")
  2. → 다음 단계 클릭하여 대본 기획으로 이동
  3. 또는 🚀 이 주제로 자동 제작을 클릭하여 자동 파이프라인 실행

방법 2: YouTube 트렌드 참고

  1. 📡 트렌드 불러오기 클릭 → 현재 한국 인기 영상 12개 표시
  2. 관심 있는 트렌드를 참고하여 주제 구상

방법 3: AI 주제 추천

  1. 카테고리(역사, 과학, AI 등), 타겟, 키워드 선택
  2. 🔍 AI 주제 추천받기 클릭
  3. 6개 주제가 카드 형태로 표시 — 예상 조회수, 난이도, 키워드 포함
  4. 마음에 드는 카드를 클릭하면 주제가 자동 입력

방법 4: 인기 주제 선택

카테고리 탭(역사, 과학, AI, 미스터리 등)에서 사전 준비된 인기 주제를 클릭합니다.

2 대본 기획

Claude AI가 영상의 전체 구조를 설계합니다.

설정 항목

  • 영상 주제 — 1단계에서 선택한 주제가 자동 입력
  • 타겟 시청자 — 10대 ~ 50대 이상, 전 연령
  • 영상 길이 — 1분(쇼츠) ~ 30분
  • 영상 언어 — 한국어, 영어, 중국어, 일본어, 스페인어
  • 톤 — 진지/무게감, 따뜻/감성, 긴박/흥미, 교육/차분
  • 이미지 스타일 — 30종 이상 선택 가능
  • 특별 요청 — 추가 참고사항 자유 입력

출력 결과

  • 영상 구조 (오프닝~CTA)
  • 8~10개 장면 구성과 비주얼 설명
  • Fact-Check 체크리스트
  • 참고 자료/출처 가이드

📋 기획안 생성 버튼을 클릭하면 기획안이 생성되고, 생성된 내용을 검토한 후 다음 단계로 진행합니다.

3 대본 작성

Claude AI가 기획안을 바탕으로 완성된 나레이션 대본을 작성합니다.

설정 항목

  • 분량 — 250자(1분 쇼츠) ~ 6,000자(30분)
  • 나레이션 스타일 — 3인칭 나레이터, 이야기꾼(구연), 리포터, 대화체
  • 영상 언어 — 선택한 언어로 본문 작성

대본 형식

대본은 [장면 N: 제목 | 이미지: 비주얼 묘사] 형식으로 장면이 구분됩니다. 이 장면 헤더 정보가 4단계 이미지 생성에 활용됩니다.

생성된 대본은 편집 가능한 텍스트 영역에 표시됩니다. 직접 수정한 후 다음 단계로 진행할 수 있습니다.

4 이미지/영상 생성

대본의 장면별로 시각 자료를 생성합니다. 두 가지 모드를 선택할 수 있습니다. 5~30개 장면까지 생성 가능하며, 생성된 모든 이미지/영상이 프리뷰에 표시됩니다.

모드 A: 이미지 기반 (GPT Image-1)

  1. 소스 모드를 "이미지 기반"으로 선택
  2. 스타일, 비율(16:9/9:16/1:1), 장면 수(5~30) 설정
  3. ① 프롬프트 생성 (Claude) 클릭 → 각 장면의 영문 이미지 프롬프트가 생성
  4. 프롬프트를 검토/수정
  5. ② 전체 이미지 생성 (GPT Image-1) 클릭 → HD 이미지(1536×1024) 순차 생성
  6. 개별 장면에서 🔄 재생성 가능

모드 B: 영상 기반 (Pexels 스톡)

  1. 소스 모드를 "영상 기반"으로 선택
  2. ① 프롬프트 생성 → 각 장면의 검색 키워드 생성
  3. ② 전체 영상 클립 다운로드 → Pexels에서 HD 영상 자동 다운로드 (최대 30개)
🎬 Pexels 영상 검색 특징
  • 시대·배경 매칭 — 대본의 시대·장소에 부합하는 키워드로 검색 (고대 주제→고대 관련 영상, 현대 주제→현대 영상)
  • 안전 검색 — Pexels API safe_search=true 적용, 음란·폭력·부적절 콘텐츠 자동 차단
  • 중복 방지 — 프로젝트 단위로 사용된 영상 ID 추적, 동일 영상 재사용 방지
  • 자동 fallback — 검색 결과 없으면 modifier 변경 → 일반 키워드 순으로 재시도 (최대 4단계)
금지 콘텐츠: 폭력, 무기, 범죄, 성인, 음란, 약물, 혐오 관련 영상은 키워드 생성 단계에서 차단되며, Pexels API 안전 검색으로 이중 필터링됩니다.

5 TTS 음성 생성

ElevenLabs API로 대본을 자연스러운 나레이션 음성으로 변환합니다.

설정 항목

  • 언어 선택 — 한국어, 영어, 중국어 (음성 추천에 반영)
  • 음성 선택 — 추천 음성 카드 또는 전체 목록에서 선택
  • 안정성 (stability) — 0(감정적/변화多) ~ 1(일관적/안정적)
  • 유사도 (similarity) — 원본 음성 톤 재현 정도

사용 방법

  1. 대본에서 자동 추출된 텍스트 확인 (편집 가능)
  2. 음성 선택 → 🔊 샘플 듣기로 미리 확인
  3. 🎙️ TTS 음성 생성 클릭
  4. 4,900자 초과 시 자동으로 청크 분할 → 연결
  5. 생성된 오디오 플레이어에서 확인
🔧 음성 품질 보장 기술
  • 청크 간 문맥 연결 — 장문 분할 시 각 청크에 앞뒤 1,000자씩 previous_text/next_text 전달하여 톤·억양 연속성 유지
  • 외국어 자동 필터 — 한국어 영상에서 중국어·일본어 문자가 과반인 줄을 자동 제거 (TTS가 외국어를 읽는 것을 방지)
  • 오디오 정규화 — YouTube 권장 -16 LUFS로 자동 정규화, 일정한 볼륨 유지
  • 청크 경계 처리 — acrossfade 80ms crossfade로 청크 경계 클릭 노이즈 제거
권장: stability=1, similarity=1 — 청크 간 음성 톤 일관성이 높아집니다. 감정적 나레이션이 필요하면 0.3~0.5로 낮추세요.

8 썸네일 생성

설정 항목

  • 스타일 — 드라마틱, 미니멀, 호기심 자극, 시네마틱
  • 해상도 — 16:9 (1280×720) / 9:16 (720×1280) 자동 적용

텍스트 디자인

Claude AI가 제목에서 핵심 키워드를 추출하여 강조 표시합니다.

🎨 한국어 영상 썸네일
[단독]                    ← 빨간 라벨

🌐 외국어 영상 썸네일 (이중 언어)

  3. 생성 실패 시 안전한 대체 프롬프트로 재시도 (최대 3회)
  4. Claude가 제목에서 highlight(강조) + sub(보조) + ko(한국어 번역) 추출

CJK 폰트(NotoSansCJKsc-Bold.otf)가 레포에 포함되어 있어 중국어·일본어·한국어 모두 정상 렌더링됩니다.

🔑 Google 로그인 + API 설정

우측 상단 버튼으로 Google 로그인 후 API 키를 관리합니다. 최초 1회 입력하면 DB에 영구 저장되어 재로그인 시 자동 로드됩니다.

Google 로그인

  1. 우측 상단 G 로그인 클릭
  2. Google 계정 선택 → 권한 승인
  3. 로그인 완료 → 프로필 사진 + 이름 표시
  4. 클릭 시 로그아웃
사전 설정 필요: Google Cloud Console에서 OAuth 2.0 Client ID 생성 + Railway Variables에 YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET 설정 필요. 자세한 내용은 Railway 배포 가이드 참고.

⚙️ API 설정 모달

  1. 우측 상단 ⚙️ 설정 클릭
  2. API 키 입력:
    • Anthropic (Claude AI) — 대본 기획, 작성, 메타데이터, 번역 필수
    • OpenAI (GPT Image) — 장면 이미지, 썸네일 생성
    • ElevenLabs (TTS) — 나레이션 음성 변환
    • Pexels (스톡 영상) — 영상 기반 모드 (무료)
    • YouTube Client ID / Secret — Google 로그인 + 업로드
    • YouTube Refresh Token — YouTube 업로드 인증 (OAuth Playground에서 발급)
  3. 💾 저장 → 즉시 반영 (서버 재시작 불필요)

YouTube Refresh Token 발급 방법

  1. OAuth Playground 접속
  2. 우측 ⚙️ → Use your own OAuth credentials 체크
  3. Client ID / Secret 입력
  4. 좌측 scope 선택: youtube.upload, youtube, userinfo.profile, userinfo.email
  5. Authorize APIs → Google 로그인
  6. Exchange authorization code for tokens 클릭
  7. Refresh token 값 복사 → ⚙️ 설정에 붙여넣기
Google Cloud Console → OAuth 2.0 → 승인된 리디렉션 URI에 https://developers.google.com/oauthplayground 추가 필요.

할당량 확인

할당량 증가 요청

  1. YouTube API 할당량 요청 양식 접속
  2. 프로젝트 번호, 요청 할당량(50,000~100,000), 사용 목적 작성
  3. 처리 기간: 2~4주

할당량 절약 방법

방법효과

💡 팁 및 권장 설정

🎯 첫 영상 제작 권장 설정
  • 영상 길이: 10~15분
  • 이미지 수: 8장
  • 스타일: 유럽풍 애니메이션 또는 시네마틱
  • 음성 안정성: 1, 유사도: 1
  • 장면 전환: 페이드 0.8초
  • Ken Burns: 다양한 효과
  • SRT 자막: 자동 생성 + burn
⚡ 빠른 제작 팁
  • 자동 제작 모드를 사용하면 주제 입력 후 모든 과정이 자동 실행됩니다
  • 각 단계 결과는 실시간으로 인라인 프리뷰됩니다
  • 프로젝트는 자동 저장되며, 프로젝트 관리 메뉴에서 이어하기 가능
