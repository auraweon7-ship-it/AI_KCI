❓ 시작 페이지 사용법

🔍 통합 검색 (Ctrl+K)
Ctrl+K 또는 헤더 ⌘ 버튼 — 등록된 링크를 즉시 검색해 엽니다.
접두어 검색: k 키워드=KCI 논문 · r=RISS · s=Scholar · g=구글 · n=네이버 · y=YouTube
🗂 메뉴·카드
· 전체 탭: 모든 카테고리를 한 페이지로 — 섹션 헤더 클릭 시 접기/펼치기, "전부 열기"로 일괄 오픈, 네온 외곽선 카드
· 🏫 대학 행정·평가: 연구·취업·재정·평가·통계·협의체·순위·기관·입시·채용·국제화를 하위 섹션으로 통합
· 🎓 대학: 권역별 지도 + 대학 목록(지도에서 사이드바·지역별 접기, 대학알리미 바로가기)
· 카드 마우스 오버 시 📌 고정 · ✏️ 편집 · ✕ 삭제, 드래그 정렬, 헤더 정렬 드롭다운
· "+ 링크 추가"로 어느 탭에서든 새 카드 등록
📈 대학통계 대시보드 (Claude API 키 필요)
전국 국립·사립 199개 대학을 권역별·국립/사립 필터로 선택 → Claude AI가 대학알리미·재정알리미 공시지표(신입생 경쟁률·취업률·교육비·장학금·기숙사수용률 등 10대 지표)를 종합해 레이더·도넛·게이지·라인 차트 + SWOT 분석 대시보드 생성. 국립/사립·권역별 연구실적 집계(실측)도 제공.
⚖️ 법령 AI 비서 (팝업, Claude API 키 필요)
국가법령정보 공동활용 API + Claude로 고등교육법·사립학교법 등 대학 관련 법령을 검색·해설하는 채팅 팝업. 답변에 근거 조문·참조 법령 링크 표시.
🔑 API · 📱 APP · 🔖 내 북마크 · 📜 좋아하는 시 (로그인·승인 필요)
헤더 🔑 API=API 키 관리(별표·정렬·마스킹·복사, JSON 파일 가져오기/내보내기).
헤더 📱 APP=앱·서비스를 이름·URL·선호도(⭐1~5)로 관리(JSON 가져오기/내보내기).
🔖 내 북마크=크롬 등 표준 HTML 북마크 가져오기/내보내기로 이전. 카드는 도메인 기준 대분류 10개(동영상·개발·AI·학술·정부·블로그·포털·쇼핑·뉴스·기타)로 자동 분류, 그룹별 외곽선 색 구분.
📜 좋아하는 시=한국 현대시 220여 편을 주제별·시인별로 분류, 찾기(시·시인·구절)·⭐ 즐겨찾기·➕ 시 등록(내 시 추가·삭제) 제공. 카드 클릭 시 전문 보기 + 🔊 낭송(ElevenLabs).

· 체크 시 취소선, 마감 지난 항목 빨간 강조, 완료 숨김·진행률 바

2. 왼쪽 시작 그룹 클릭
3. "특정 페이지 또는 페이지 모음 열기" 선택 → "새 페이지 추가"

3. 시작 페이지: "특정 페이지" 선택 → https://startgage.up.railway.app 입력
4. 새 탭도 같은 화면에서 "지정 페이지"로 설정 가능

☁️ 클라우드 자동 동기화 (로그인 시)
Google 로그인하면 API·APP·캘린더·강의·TO-DO·즐겨찾기가 서버(Railway Postgres)에 자동 저장됩니다.
→ 다른 PC·휴대폰에서 같은 계정으로 로그인만 하면 데이터가 그대로 나타납니다. 저장·복원 버튼 누를 필요 없이 실시간 동기화.
💾 Google Drive 백업 / 복원
설정 → ☁️ Drive 백업 또는 📤 내보내기=현재 모든 데이터·설정(API·APP·캘린더·TO-DO·북마크·좋아하는 시·좋아하는 음악·API키·도서/유튜브 키워드 등 전부)을 스냅샷 저장.
새 기기에서 로그인 후 ☁️ Drive 복원 / 📥 가져오기 → 계정이 달라도 현재 계정으로 자동 매핑되어 전부 복원.
최초 1회 Drive 백업하면 이후 30분마다 자동 백업(팝업 없이 조용히 실행).
내 북마크는 표준 HTML(Netscape) 형식으로도 내보내기/가져오기 가능(브라우저 호환).
🛡 관리자 승인 (접근제어)
보안을 위해 로그인 사용자는 관리자 승인 후 전체 기능 사용 가능.
헤더 🛡=관리자 패널(사용자 목록·성명·가입일·승인·수정·삭제).
미승인 시 캘린더·TO-DO·대학통계·법령AI·내 북마크·API·APP 사용이 제한됩니다.
🔒 로그인·데이터 안내
· 위 기능은 로그인 + 관리자 승인 후 표시·저장 (계정별 분리).
· 로컬(localStorage)은 캐시로 유지 → 오프라인 열람 가능.
· 한 번 로그인하면 재방문 후에도 자동 유지 (로그아웃 전까지).
· API 키 등 민감 정보는 본인 계정 공간·이 브라우저에만 저장됩니다.
