CORE FEATURES

주요 분석 기능

☁️
워드클라우드
논문 제목과 초록을 통합 분석하는 인터랙티브 워드클라우드. 전체·고피인용·최신 필터 전환 지원.
🗺️
저자기관 지도
Google Maps API로 전국 14개 연구기관을 지도에 시각화. 클릭 팝업으로 상세 정보 확인.
📊
20종 분석 차트
시계열·산점도·버블·레이더·폴라·도넛·히트맵·스파크라인 등 다양한 차트로 데이터를 다각도 분석.
🤖
차트별 AI 분석
모든 차트 하단에 Claude AI가 생성한 심층 분석 텍스트 제공. 수치 해석·원인 분석·시사점·예측 포함.
🧩
토픽 모델링
LDA 기반 6개 핵심 연구 군집 도출. 기술·교육실천·생성형AI·정책·윤리·융합 연구군을 자동 분류.
👥
저자 협업 네트워크
연구자 간 협업 관계를 SVG 네트워크로 시각화. 노드 클릭 시 대표 논문 5편 팝업 표시.
🧠
지식 네트워크 맵
핵심 키워드 간 의미적 연관성을 방사형 네트워크로 표현. 연결선 굵기가 공출현 강도를 반영.
📖
선행연구 분석
4개 유형으로 분류된 학술논문 형식의 선행연구 분석 자동 생성. "(저자, 연도)" 인용 형식 적용.
