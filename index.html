📖 사용법

🔐 시작하기: 구글 로그인

왜 로그인이 필요한가요?

로그인하면 AI 분석 기능(연구 동향 인사이트, 맞춤형 추천, 논문 구조 생성 등)을 사용할 수 있습니다. 로그인하지 않아도 검색과 차트 조회는 가능하지만, AI 기능은 로그인 후 이용 가능합니다.

로그인 방법

① 화면 오른쪽 상단의 "G 로그인" 버튼을 클릭합니다.
② 구글 계정을 선택하거나 이메일/비밀번호를 입력합니다.
③ 로그인 완료 시 버튼이 프로필 아이콘으로 바뀌며, AI 기능이 활성화됩니다.

🔍 AI 분석 메뉴

📌 검색

연구 키워드, 학문 분야, 대학명 등을 입력하면 KCI에 등록된 학술논문을 검색합니다.
사용법: 상단 검색창 또는 '검색' 메뉴에서 키워드 입력 → "검색" 버튼 클릭 → 논문 목록, 저자, 학술지 정보를 확인합니다.

📌 최근 연구 흐름

특정 학문 분야의 최근 5년간 연구 트렌드를 한눈에 파악합니다.
사용법: 학문 분야(예: 교육공학) 선택 → 기간 설정 → 키워드 입력 → "분석하기" 클릭 → 연도별 논문 수 변화, 분야별 비율, AI 동향 인사이트를 확인합니다.

📌 핵심 키워드 트렌드

관심 키워드가 학술 연구에서 얼마나 활발하게 사용되는지 연도별 추이를 분석합니다.
사용법: 키워드 입력(예: 인공지능, 머신러닝) → "트렌드 분석" 클릭 → 연도별 키워드 빈도 변화 그래프와 AI 해석을 확인합니다.

📊 연구성과 분석 메뉴

📌 영향력 분석

특정 키워드 관련 논문의 학술적 영향력(인용 횟수, 인용 지수 등)을 분석합니다.
사용법: 분석할 키워드 입력 → "분석" 클릭 → 인용 분포, 피인용 상위 논문, 영향력 높은 학술지를 확인합니다.

📌 연구자 네트워크

특정 분야에서 함께 연구하는 저자들 간의 공동연구 관계를 네트워크 그래프로 시각화합니다.
사용법: 키워드 입력 → "네트워크 분석" 클릭 → 공동저자 네트워크 그래프에서 핵심 연구자와 협업 관계를 파악합니다.

🏫 연구력 분석 메뉴

📌 대학 연구력 지도

전국 대학의 연구 활동을 지도 위에 시각화하여, 지역별·대학별 연구 성과를 비교합니다.
사용법: 학문 분야 선택 → 지도에서 대학 마커 클릭 → 해당 대학의 논문 수, 주요 연구 분야, 대표 연구자를 확인합니다.

🔎 논문 탐색 지원 메뉴

📌 선행연구 탐색

키워드를 입력하면 관련 선행연구를 검색하고, 키워드 네트워크 그래프로 연구 주제 간의 관계를 시각화합니다.
사용법: 키워드 입력 → "탐색" 클릭 → 논문 목록 탭에서 관련 논문 확인, 키워드 네트워크 탭에서 주제 간 연결 관계를 파악합니다.

📌 연구 설계 도우미

AI가 연구 주제에 맞는 연구 설계(연구 방법, 분석 도구, 표본 설정 등)를 제안합니다.
사용법: 연구 주제와 분야 입력 → "연구 설계 추천" 클릭 → AI가 추천하는 연구 방법론, 분석 기법, 참고할 선행연구를 확인합니다.

✍ 논문 작성 도우미 메뉴

📌 논문 구조화

논문 제목, 연구 목적, 방법 등을 입력하면 AI가 목차와 논문 개요(약 2000자)를 자동 생성합니다.
사용법: ① 논문 제목(필수), 연구 분야, 연구 목적(필수), 연구 방법, 주요 결과, 키워드를 입력합니다.
② "논문 구조 생성" 버튼 클릭 → AI가 목차와 상세 개요를 생성합니다.
③ 한/영 전환 버튼으로 영문 개요도 확인 가능합니다.

📌 참고문헌 포맷팅

참고문헌 정보를 입력하면 APA, MLA, Chicago 등 다양한 인용 형식으로 자동 변환합니다.
사용법: '참고문헌 포맷팅' 탭 클릭 → 참고문헌 정보 입력 → 원하는 인용 형식 선택 → 변환된 결과를 복사하여 논문에 붙여넣습니다.

📋 대시보드 소개 메뉴

📌 설정 / 맞춤 인사이트

나의 학문 분야와 관심 키워드를 설정하면, AI가 맞춤형 연구 인사이트를 제공합니다.
사용법: 학문 분야, 관심 키워드, 연구 경력 등을 입력 → "저장" → 이후 분석 시 맞춤형 결과를 받을 수 있습니다.
